# VS MCP 0.6.3

Install both `VsMcp-0.6.3.vsix` and `VsMcp.Bridge.Setup-0.6.3.exe` from this release, then restart Visual Studio and reconnect the MCP client.

- Bridge Setup installs the `visual-studio` skill for Codex and Claude Code. Setup refreshes the skill on upgrade and removes its files on uninstall. Start a new conversation to load the skill.
- Bridge Setup uses Windows Restart Manager to close affected launchers when an upgrade replaces the launcher executable. Reconnect the MCP client after upgrading.

Users upgrading from 0.5.0 or earlier must update their MCP command to `%LOCALAPPDATA%\Programs\VsMcp\VsMcp.Bridge.Launcher.exe` after installing Bridge Setup.
