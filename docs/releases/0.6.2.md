# VS MCP 0.6.2

Install both `VsMcp.vsix` and `VsMcp.Bridge.Setup.exe` from this release, then restart Visual Studio and reconnect the MCP client.

- Fix project dependency queries by using Visual Studio's native solution build manager, avoiding `E_NOTIMPL` failures from DTE in some host solutions.
- Align the VSIX, Bridge and MCP server version at 0.6.2. No tools or protocol changes are added.

Users upgrading from 0.5.0 or earlier must install Bridge Setup and update their MCP command to `%LOCALAPPDATA%\Programs\VsMcp\VsMcp.Bridge.Launcher.exe`, as described in the README.
