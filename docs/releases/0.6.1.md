# VS MCP 0.6.1

Install both `VsMcp.vsix` and `VsMcp.Bridge.Setup.exe` from this release, then restart Visual Studio and reconnect the MCP client to use the updated extension and Bridge.

- `get_projects` now reports `isLoaded` using Visual Studio's solution service, so agents can distinguish unloaded projects from missing projects.
- Build workflows now direct agents to reload unloaded projects with `project_reload`, confirm they are loaded, and continue building through VS MCP. Command-line fallback remains available when the VS MCP path is blocked after inspection, with an explanation of the blocker.
- Updated tool descriptions, error guidance, English and Traditional Chinese documentation, and the generated SDK catalog. There are still 85 IDE tools and two Bridge instance-selection tools.

The reload workflow was verified in an isolated experimental hive: unload, inspect state, reload and successfully build. VSIX and Bridge builds, the protocol harness and SDK catalog checks passed.
