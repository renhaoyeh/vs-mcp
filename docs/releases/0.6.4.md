# VS MCP 0.6.4

Install both `VsMcp-0.6.4.vsix` and `VsMcp.Bridge.Setup-0.6.4.exe`. Restart Visual Studio and reconnect the MCP client.

- `launch_vs_instance` checks whether a reachable Visual Studio instance already has the requested `.sln` or `.slnx` open. If there is one compatible match, it returns that instance. If several instances have the solution open, it returns the candidates for explicit selection.
- If the solution is absent, the bridge starts an independent Visual Studio process and verifies the loaded solution path. Pass `forceNew: true` to explicitly open another process for the same solution. The new process stays open when the bridge exits.
