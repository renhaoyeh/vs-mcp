# VS MCP 0.6.0

Install both assets from this release:

- `VsMcp.vsix`: Visual Studio 2026 extension.
- `VsMcp.Bridge.Setup.exe`: per-user Windows x64 Bridge installer, including its .NET runtime and a native launcher.

Bridge installation now works independently of Visual Studio startup. MCP clients use the fixed `%LOCALAPPDATA%\Programs\VsMcp\VsMcp.Launcher.exe` path. Setup creates `mcp-config.json` beside it for copying into the client's supported configuration format, preserving existing settings.

Each Bridge build is installed into an immutable version directory. Setup verifies the complete SHA-256 manifest before atomically selecting the new build. Existing MCP connections keep their current Bridge; reconnect to start the new version. Reinstalling or upgrading the Bridge payload does not replace executable files used by an active connection. If the native launcher itself changes, Windows may require MCP connections to close before that file can be updated.

For users upgrading from 0.5.0 or earlier, replace the old `%LOCALAPPDATA%\VsMcp\Bridge\VsMcp.Bridge.exe` MCP command with the new launcher path once, then reconnect. The legacy directory and processes are preserved; remove the legacy directory only after every client has migrated and stopped using it. VSIX startup no longer copies Bridge files.

The installer supports normal Windows uninstall. Close MCP clients before uninstalling. Old version directories are retained until uninstall.

The IDE tool catalog is unchanged: 85 IDE tools and two Bridge instance-selection tools. The connection still requires explicit `list_vs_instances`, `connect_vs_instance`, and identity verification before IDE operations.
