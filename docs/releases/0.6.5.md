# VS MCP 0.6.5

Install `VsMcp-0.6.5.vsix` and `VsMcp.Bridge.Setup-0.6.5.exe`, then restart Visual Studio and reconnect the MCP client.

- On first load in a supported Visual Studio profile (18.11 or later), the extension enables **Stop solution build after first failure**. Later launches preserve your choice.
- Bridge Setup installs the `vs-mcp` skill where Codex and Claude Code can discover it. Setup removes the old nested skill files on upgrade.
